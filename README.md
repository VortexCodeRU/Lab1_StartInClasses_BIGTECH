# ЛАБОРАТОРНАЯ РАБОТА №1 (ТРЕК BIGTECH). КЛАССЫ И ОБЪЕКТЫ. ПОЛЯ, МЕТОДЫ, МОДИФИКАТОРЫ ДОСТУПА. ИНКАПСУЛЯЦИЯ.

## Цель работы. Вспомнить устройство класса и научиться проектировать класс так, чтобы он сам защищал корректность своих данных: описать поля и методы, закрыть состояние модификаторами доступа, проверять правила предметной области в конструкторах и методах, безопасно хранить внутри себя другие объекты.

## Описание задания

Реализация двух классов на языке **C#**:
1. **`Track`** — класс-сущность (трек)
2. **`PlayList`** — класс-контейнер (плейлист)

## Постановка задачи

### Класс `Track` (трек)

**Поля (все `private`):**
- `key` — номер трека (`int`)
- `title` — название (`string`)
- `artist` — исполнитель (`string`)
- `duration` — длительность в секундах (`int`)
- `count_listen` — число прослушиваний (`int`)
- `genre` — массив жанров (`string[]`)
- `count_tracks` — кол-во созданных объектов (`int`) (по ум-ю 0)
- `MAX_DURATION` — максимальная длительность в секундах (`int`) (по ум-ю 3600)

**Правила:**
- Длительность от 1 до 3600 секунд
- Число прослушиваний может только расти
- Название непустое
- Номер неотрицательный

**Конструкторы:**
- Полный: `Track(key, title, artist, duration, count_listen, genre)`
- Упрощённый: `Track(key, duration=1, count_listen=1)`

### Класс `PlayList` (плейлист)

**Поля (все `private`):**
- `playLists` — массив треков (`Track[]`)
- `count` — счётчик занятых мест (`int`)

**Операции:**
- `Add(track)` — добавить трек
- `Remove(key)` — удалить трек по номеру
- `Sum_duration_inSeconds()` — суммарная длительность
- `Popular_track()` — самый популярный трек
- `Sort()` — сортировка по числу прослушиваний
- `GetTracks()` — получить список треков (копия)
- `GetAllGenres()` — все уникальные жанры
- `Len()` — получить кол-во треков в плейлисте
